# BACnetAlarmScanner

The BACnet Alarm Scanner is a tool for scanning, collecting and logging alarm and event notifications from BACnet devices in building automation systems.

The focus of this project is fast visibility of active alarms, reliable event handling and structured logging for further analysis.
It is designed as a system-oriented tool for real BACnet environments, not as a demo or protocol experiment.

## Scope
- Scan and receive BACnet alarm and event notifications
- Structured logging of alarm data
- Focus on robustness and long-running operation
- Intended for use in building automation and system integration contexts
